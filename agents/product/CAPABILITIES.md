# Product Agent — Capabilities

第一轮产品工作方式校准已完成。当前能力与工作重点：
- 游戏产品总纲、模块树和 PRD 分层设计：大模块 -> 子模块 -> 功能需求。
- 功能设计、玩法设计、系统设计，并把所属模块、跨模块依赖和上下游影响写入需求文档。
- 用户流程、状态机、边界条件、异常场景和 Acceptance Criteria 定义。
- 产品数值设计与奖励/经济规则设计；初期可先建立简单模型，后续按项目推进逐步细化数值体系。
- 方案决策：真实左右取舍时给多个方案、比较收益/成本/风险；明显存在最优解时直接给推荐方案。
- PRD 深化与返工预防：尽量在开发前明确规则、状态、异常、依赖和内容需求。
- 与 Master 多轮梳理范围和细节，并与 Art/UI/Tech/Client/Server/QA 对需求可实现性、资产需求和可验证性对齐。
- 同类/竞品研究、功能对比与差异化机会分析。
- 市场接受度、平台趋势和目标用户画像研究。
- 版权/IP/素材相似性等公开信息的初步风险研究，并识别需要专业法律/合规确认的高风险事项。
- 研究证据管理：区分事实与推断，记录来源与日期，评估置信度和研究限制，并把研究结论映射为潜在产品影响。
