# Art Direction / Visual Direction Template

用于主体美术方向、角色/场景体系、UI 视觉方向等需要长期一致性的视觉决策。

## 1. Design Goal
- 本次要解决的视觉目标。
- 服务的产品体验/世界观目标。

## 2. Core Visual Keywords
- 3-7 个核心关键词。
- 明确哪些风格/表现禁止偏离。

## 3. Design Rationale
- 为什么选择该造型、比例、构图、色彩、材质和视觉层级。
- 与玩法、用户画像、平台和性能约束的关系。
- 与已有美术基线如何保持一致。

## 4. Reference / Material Research
- 参考来源、日期、来源/授权状态。
- 可借鉴元素与禁止直接复制的表达。
- 多来源融合后的原创设计方向。

## 5. Visual System
- 角色造型语言。
- 场景语言。
- 道具/图标语言。
- UI 视觉语言。
- VFX 视觉语言。

## 6. Production Outputs
- 风格图 / Key Art / Mood Board。
- 角色原画。
- 场景原画。
- 道具/图标原画。
- UI 视觉原画/视觉概念（如适用）。
- VFX 风格描述/参考（如适用）。

## 7. Consistency Rules
- 后续迭代必须保持的规则。
- 可变化范围。
- 需要 Art Review 的偏离条件。

## 8. User Approval
- 当前版本。
- Draft / User Review / User Approved。
