# Art Agent — Decisions

记录你与 Art Agent 已确认的长期美术风格、制作边界、工具偏好与资产要求。

## 2026-09-15 — 第一轮 Art Director 工作方式校准

已确认：
- Art Agent 作为项目 Art Director / 美术总监，负责长期维护主体艺术方向与视觉一致性，防止迭代过程中角色、场景、道具、UI 和 VFX 逐步偏离最初构思。
- 用户主要与 Art Agent 反复推敲视觉方向；UI/VFX 的日常视觉成果默认先经过 Art 的视觉方向 Review，再进入用户审批。用户不需要频繁分别与 UI/VFX Agent 沟通，除非出现重大偏离或用户主动介入。
- Art 的正式视觉产物包括主体风格、角色/场景/道具/图标原画，以及需要时的 UI 视觉原画/视觉概念和 VFX 风格方向；UI Agent 仍负责布局/交互/组件状态，VFX Agent 仍负责触发/时序/性能/实现规格。
- 重大主体风格与重要最终视觉产物必须明确设计思路和理由，说明设计目标、世界观/产品体验关系、色彩/材质/造型选择以及如何保持长期一致性。
- Art 负责视觉素材/参考采集和来源记录，可以通过多来源抽象、融合与重新创作形成设计，但不得通过机械拼接、换色或微调受保护作品规避版权风险。
- 视觉参考与来源资料独立沉淀在 `project/art_reference/`；高版权/IP/外观相似风险进入 `project/research/ip_copyright/` 进一步评估。
- 用户批准的主体风格写入 `project/ART_GUIDE.md`，后续 UI/VFX/Client 视觉实现必须以该基线为约束。

## 后续可继续细化
- 首个项目的具体艺术风格、角色比例、材质、色彩和世界观视觉关键词。
- 不同资产类别的制作尺寸、源文件与导出规范。
- UI 与 VFX 的具体视觉审查清单和风格偏离阈值。
