# 项目美术基线

## 状态
- 当前正式 Art Direction：`USER_APPROVED`
- 批准版本：v0.1
- 正式来源：`deliverables/art/GAME-003-ART-DIRECTION/ART_DIRECTION_v0.1.md`
- 概念资产：10 级猫咪体系、棋盘氛围、HUD 视觉方向 SVG

## 核心视觉关键词
1. 圆润软萌
2. 贴纸感清晰轮廓
3. 温暖奶油色
4. 等级一眼可辨
5. 轻量绘本
6. 玩法可读性优先

## 角色视觉语言
- 猫咪主体使用接近圆形或短椭圆的大轮廓，耳朵、尾巴、毛束等突出部件保持贴身。
- 可见主体轮廓必须与实际碰撞占地足够接近，禁止使用大帽檐、长尾、大翅膀等制造虚假碰撞体积。
- L1–L10 通过体积、内部花纹、贴身特征和有限装饰逐级增强。
- L1–L3 必须在小尺寸 Current / Next 预告中仍能明显区分。
- L7–L10 可以更丰富，但仍保持单一清晰大轮廓。

## 场景与棋盘语言
- 主玩法容器采用“猫咪游戏软垫盒”方向，不使用与参考合成游戏高度相似的玻璃容器表达。
- 背景使用低对比、低信息密度的温暖室内抽象元素，不能干扰猫咪边缘和危险线。
- 顶部投放区保持干净，危险线使用短虚线 + 小布签语言。

## 色彩基线
- 背景奶油：`#FFF3DE`
- 容器暖木：`#D9A66F`
- 深描边：`#5B4A42`
- HUD 奶白：`#FFF9EF`
- HUD 深字：`#4A3D38`
- 安全辅助蓝绿：`#85C9B8`
- 危险珊瑚红：`#F16F67`
- 合成高光黄：`#FFD66B`

危险红只承担警告/失败语义，不作为普通装饰主色。

## UI 视觉方向
- 圆角软贴纸 / 布签形态。
- 分数为第一信息优先级，Next 为第二，暂停/设置为第三。
- 浅底深字、大留白、低装饰密度。
- 不使用复杂金属框、宝石渐变或重拟物按钮。
- 具体布局、交互、组件状态由 UI Agent 负责，但必须遵循本视觉基线。

## VFX 视觉方向
- 合成：短促软弹 + 少量星点/毛屑，颜色取结果猫咪主色并搭配暖黄高光。
- 连锁：节奏增强但不遮挡邻近猫咪。
- 危险：危险线呼吸 + 轻微珊瑚红晕，禁止全屏频闪。
- Game Over：柔和压暗/轻微去饱和，不默认使用强烈震屏。

## 一致性约束
必须重新进行 Art Direction Review 的变化包括：
- 整体切换写实、像素、3D、强赛博等风格；
- 猫咪从圆润短体改成长体、明显四肢或大外挂装饰体系；
- 主棋盘容器视觉逻辑整体更换；
- UI 大量引入高饱和、复杂纹理或强拟物语言。
