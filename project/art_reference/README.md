# Art Reference Repository

This directory stores visual references/research/source records, not final production assets.

For each important reference record:
- source/link/origin
- collection date
- source type (original/web/asset library/generative reference/etc.)
- known license/copyright state; use UNKNOWN when unknown
- borrowed aspects: color/proportion/material/composition/cultural elements/function
- protected expression not to copy
- how the final design was reconstructed/abstracted/fused/recreated into the project's own visual language

## Categories
- characters/
- scenes/
- props/
- ui/
- vfx/
- misc/

## Copyright / Appearance Rules
- inspiration/reference does not equal copying rights
- no one-to-one copying, recoloring, minor tweaks or recognizable near-copy
- multi-source fusion does not automatically eliminate risk
- unknown source/license cannot directly become a final production asset
- high-risk issues are researched under `project/research/ip_copyright/` and may require professional legal/licensing confirmation
