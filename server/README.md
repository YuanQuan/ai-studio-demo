# Server Entry

Default mini-game server baseline: Node.js + NestJS + TypeScript modular monolith, standard WebSocket using `ws`, Protobuf, MySQL + Redis.

The actual implementation may live under `apps/server/` in the Monorepo. This directory is retained as a project-level entry/readme location for Server Agent guidance if desired.

Server implementation must follow approved Product/Tech/Protocol artifacts, keep critical state server-authoritative, create `FEATURE_BRIEF.md` before non-trivial coding and produce `IMPLEMENTATION_REPORT.md` after implementation.
