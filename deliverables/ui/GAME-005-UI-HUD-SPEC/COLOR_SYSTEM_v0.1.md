## 1. 基础色
| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#FFF3DE` | 奶油底色，低干扰 |
| HUD 卡片 | `#FFF9EF` | 主要信息承载 |
| 主文字 | `#4A3D38` | 分数、标题、主标签 |
| 深描边 | `#5B4A42` | 图标/卡片/角色边界辅助 |
| 容器暖木 | `#D9A66F` | 棋盘边界/场景辅助 |
| 安全辅助 | `#85C9B8` | 非警告状态辅助提示 |
| 危险色 | `#F16F67` | 仅 WARNING / Game Over 语义 |
| 合成高光 | `#FFD66B` | 分数轻反馈、合成视觉协同 |

## 2. 状态色规则
- `SAFE`：危险线使用深描边/暖木色的低透明度版本，禁止使用危险红常驻。
- `WARNING`：使用 `#F16F67`，并配合线型/呼吸节奏，不仅依赖颜色。
- `pressed`：优先通过缩放/阴影改变，不额外发明新高饱和颜色。
- `disabled`：降低透明度和对比，不使用红色表示普通禁用。

## 3. 文本
- 主分数：主文字色，高对比。
- 次级标签“下一只”等：主文字色 70%–80% 视觉强度。
- 警告文字：危险色 + HUD 奶白底，确保可读。

## 4. 使用限制
- 危险色不用于普通装饰或猫咪常规主色强调。
- 合成高光只短时出现，不作为常驻按钮主色。
- 不引入重渐变、金属质感或宝石高光体系。
- 若后续 UI 新增颜色，应先检查是否能由本系统组合表达；新增主体色需 Art Review。
