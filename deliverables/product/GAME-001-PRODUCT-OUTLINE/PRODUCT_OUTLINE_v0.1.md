# Product Outline v0.1 — 猫咪合成休闲小游戏

- Task ID: `GAME-001-PRODUCT-OUTLINE`
- Status: `DRAFT / USER_REVIEW`
- Product concept: 以“下落 + 物理堆叠 + 同级合成”为核心的竖屏休闲小游戏，主题为原创猫咪形象。
- Working title: `猫猫叠叠乐`（临时名，可后续修改）

## 1. 游戏目标

### 核心体验
玩家从屏幕上方放下不同等级的猫咪，让它们在容器内自然碰撞、滚动、堆叠；两个相同等级的猫咪接触后合成为更高一级猫咪。核心乐趣来自空间管理、连续合成、意外连锁反应和“再放一个就能合成”的紧张感。

### 目标玩家
- 喜欢轻量、低学习成本、单局可快速重开的移动端休闲玩家。
- 适合碎片时间游玩，单局目标时长建议约 3–8 分钟。
- 不依赖复杂剧情、长期养成或高频社交即可获得完整体验。

### 核心循环
1. 查看当前待投放猫咪与下一只预告。
2. 左右移动投放位置。
3. 释放猫咪，让其受物理规则下落并堆叠。
4. 同等级猫咪接触后合成为更高等级，并获得分数。
5. 通过规划落点制造连续合成、释放空间。
6. 当猫咪堆叠长期越过危险线时结束本局。
7. 查看本局分数 / 最佳分数，并立即重新开始。

### 局内长期目标
- 尽可能获得更高分。
- 尽可能合成最高等级猫咪。
- 持续突破个人最佳分数。

### 当前版本范围（MVP）
- 单一无尽模式。
- 竖屏单手操作。
- 10 个猫咪合成等级（v0.1 建议值）。
- 当前猫咪 + 下一只预告。
- 仅低等级猫咪进入随机投放池，建议为等级 1–3。
- 同级碰撞合成、分数结算、最高分记录。
- 危险线 + 短暂容错后判定游戏结束。
- 首页、游戏内、结算、重新开始的完整闭环。
- 基础新手提示、音效、合成反馈和简单特效。
- Web 开发调试，并保留微信小游戏 / 抖音小游戏平台适配结构。

### 明确不做（MVP）
- 不做付费、广告设计或商业化系统。
- 不做账号登录、云存档、跨设备同步。
- 不做角色养成、猫咪收集图鉴、装备、商店、货币等长期 Meta。
- 不做在线排行榜、好友、分享激励、多人玩法。
- 不做活动、赛季、每日任务等运营系统。
- 不做服务端权威玩法；MVP 以纯客户端单局为主。
- 不复制参考游戏的名称、角色、图形资产、UI排版、音效、具体美术风格或其他受保护表达。

## 2. 产品原则

1. **一眼能懂**：玩家无需长教程即可理解“相同猫咪碰到一起会升级”。
2. **物理结果可读**：猫咪造型可以可爱，但碰撞轮廓必须清晰、稳定，避免视觉与实际碰撞严重不一致。
3. **失败有预警**：危险线、临界提示和结束容错必须清楚，避免玩家觉得突然死亡。
4. **重开极快**：结算页到下一局不应被复杂流程打断。
5. **主题原创**：保留“合成 + 堆叠”的玩法类型，但猫咪等级体系、命名、美术、UI和音画反馈建立独立视觉身份。

## 4. 模块拆分

### 4.1 核心投放与物理棋盘
- 模块目标：让玩家通过简单水平定位决定猫咪落点，并让落下后的物理堆叠成为主要策略来源。
- 玩家入口：进入一局游戏后立即开始。
- 子模块：待投放猫咪、水平移动、释放、重力、碰撞、容器边界、静止/运动状态。
- 核心规则：待投放猫咪在顶部安全区域左右移动；玩家确认后释放；释放后玩家不再直接操控该猫咪。
- 依赖模块：猫咪等级与合成、危险线。
- 数据/数值需求：重力、摩擦、弹性、猫咪尺寸、容器宽高、生成高度；后续由玩法调优确定。
- UI/Art/VFX需求：投放指示清楚；猫咪轮廓与碰撞范围尽量一致。
- 技术影响：需要稳定的 2D 物理模拟，并保证不同平台帧率下规则表现尽量一致。
- QA重点：高速碰撞穿透、卡边、重复触发合成、异常重叠、不同帧率表现。
- 当前状态：OUTLINE。

### 4.2 猫咪等级与合成
- 模块目标：提供持续成长反馈与空间释放机会。
- 玩家入口：两个相同等级猫咪在棋盘内发生有效接触。
- 子模块：等级链、合成资格、合成生成、最高等级处理、连锁合成。
- 核心规则：两个相同等级猫咪合成一个下一等级猫咪；最高等级不再继续升级。一次物理变化可自然触发多次连续合成。
- v0.1 建议：共 10 级；随机投放池只出现 1–3 级，避免中高等级直接掉落破坏成长节奏。
- 依赖模块：核心物理、分数。
- 数据/数值需求：等级ID、尺寸、质量、基础得分、投放权重。
- UI/Art/VFX需求：每级猫咪必须轮廓、体积和视觉身份明显可区分；具体猫咪品种/造型由 Art 阶段决定。
- 技术影响：合成需避免同一对象一帧内被重复消费。
- QA重点：三体同时接触、连续合成、边界附近合成、最高等级行为。
- 当前状态：OUTLINE。

### 4.3 分数与局内目标
- 模块目标：让每次成功合成都有即时奖励，并形成可重复挑战的个人成绩目标。
- 玩家入口：发生合成、结束一局。
- 子模块：合成得分、本局总分、最佳分数、结算展示。
- 核心规则：得分只由合成产生；等级越高，单次合成价值越高。具体分值表在功能 PRD / 数值配置阶段确定。
- v0.1 建议：MVP 不加入复杂连击倍率，先保证规则透明。
- 依赖模块：合成、本地持久化、结算。
- 数据/数值需求：等级分值表。
- UI/Art/VFX需求：分数增长需有即时但不遮挡玩法的反馈。
- 技术影响：最高分仅本地保存。
- QA重点：重复计分、合成链漏计、重开后分数未清零、最佳分更新错误。
- 当前状态：OUTLINE。

### 4.4 危险线与结束判定
- 模块目标：建立清晰压力，并让玩家明确知道自己为何失败。
- 玩家入口：堆叠高度接近容器顶部。
- 子模块：危险线检测、警告状态、容错计时、结束冻结。
- 核心规则：存在猫咪持续占据危险线以上区域时进入警告；若在容错期内通过物理移动/合成回落则取消；持续超时才 Game Over。
- v0.1 建议：容错时间 2 秒，后续通过手感测试调整。
- 依赖模块：物理棋盘、页面结算。
- 数据/数值需求：危险线高度、容错秒数。
- UI/Art/VFX需求：危险线、临界闪烁/音效需显著但不过度干扰。
- 技术影响：应避免刚投放、短暂弹跳造成误判。
- QA重点：抖动反复进入退出警告、合成瞬间判死、暂停时计时继续。
- 当前状态：OUTLINE。

### 4.5 页面流与局内 HUD
- 模块目标：最短路径完成开始、游玩、失败、重开。
- 玩家入口：首页。
- 子模块：首页、开始按钮、当前/下一只猫提示、分数、暂停、结算、重开。
- 核心规则：首页一键开局；结算页优先显示本局分数、最佳分数和重开按钮。
- 依赖模块：核心玩法、分数、本地存储。
- 数据/数值需求：无复杂经济数据。
- UI/Art/VFX需求：后续 UI 阶段提供正式布局与视觉稿。
- 技术影响：需适配异形屏安全区及微信/抖音小游戏可用区域。
- QA重点：快速连点、暂停/恢复、重复重开、前后台切换。
- 当前状态：OUTLINE。

### 4.6 本地持久化
- 模块目标：保存个人最佳成绩和基础设置。
- 玩家入口：自动读取/写入。
- 子模块：最佳分数、音效设置。
- 核心规则：只保存必要轻量数据；本局进行状态默认不做中途恢复。
- 依赖模块：平台适配。
- 数据/数值需求：bestScore、audioEnabled 等最小字段。
- UI/Art/VFX需求：设置入口后续 UI 决定。
- 技术影响：通过平台适配层统一 Web / 微信 / 抖音本地存储能力。
- QA重点：首次启动、数据缺失、旧数据兼容、清缓存。
- 当前状态：OUTLINE。

### 4.7 新手引导
- 模块目标：首局在几秒内让玩家理解“移动 → 放下 → 相同合成”。
- 玩家入口：首次开始游戏。
- 子模块：投放提示、合成提示、危险线提示。
- 核心规则：尽量使用场景内短提示，不做长步骤强制教程。
- 依赖模块：核心玩法、HUD。
- 数据/数值需求：首次引导完成标记。
- UI/Art/VFX需求：提示不得遮挡落点和物理区域。
- 技术影响：本地记录是否已展示。
- QA重点：跳过/重复显示、首次局快速失败、重装/清缓存。
- 当前状态：OUTLINE。

### 4.8 音画反馈
- 模块目标：强化猫咪碰撞、合成、连续升级和临界状态的愉悦感与可读性。
- 玩家入口：投放、碰撞、合成、危险、结束。
- 子模块：基础SFX、合成特效、轻量屏幕反馈、失败反馈。
- 核心规则：表现不能影响碰撞判断，也不能遮挡危险线。
- 依赖模块：Art Direction、UI、VFX。
- 数据/数值需求：事件到音画表现的映射。
- UI/Art/VFX需求：由后续正式视觉阶段确定。
- 技术影响：低端设备需支持降低粒子/震动等表现。
- QA重点：多次连锁时声音爆量、粒子堆积、性能抖动。
- 当前状态：OUTLINE。

### 4.9 设置与平台适配
- 模块目标：让同一核心玩法可在 Web 调试，并可面向微信小游戏、抖音小游戏发布。
- 玩家入口：设置 / 平台生命周期。
- 子模块：WebAdapter、WeChatAdapter、DouyinAdapter、安全区、音效设置、前后台状态。
- 核心规则：核心玩法代码不直接散落调用平台 API。
- 依赖模块：Client 架构。
- 数据/数值需求：无。
- UI/Art/VFX需求：必要设置项即可。
- 技术影响：后续由 Tech Lead 明确 Adapter 接口与平台差异。
- QA重点：Web 正式执行为默认范围；微信/抖音真机仅在明确任务中测试。
- 当前状态：OUTLINE。

## 6. v0.1 建议默认值（待用户审批）

- 画面方向：竖屏 9:16。
- 猫咪等级：10 级。
- 随机投放池：等级 1–3。
- 预告：显示 1 只“下一只猫”。
- 输入：水平移动后释放投放；具体是拖动还是点击定位在 UI/交互 PRD 中细化。
- 危险线容错：2 秒。
- MVP计分：只按合成等级计分，不加连击倍率。
- 存档：本地保存最佳分和基础设置，不保存中途残局。
- Meta：MVP 不做任何局外养成、货币、图鉴或商店。
- 在线能力：MVP 不依赖服务端。
