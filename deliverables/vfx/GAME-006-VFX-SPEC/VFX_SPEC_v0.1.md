# 核心玩法 VFX 规格 v0.1

- Task：`GAME-006-VFX-SPEC`
- 状态：`USER_APPROVED`
- Owner：VFX
- 正式上游：Core Gameplay PRD v0.1、Art Direction v0.1、Core Tech Design v0.1

## 1. 目标

用轻量、清晰、可降级的视觉反馈强化“合成成功、连续合成、危险开始/解除、Game Over”四类核心事件，同时保持猫咪边缘、碰撞关系和危险线可读性。

## 2. 总体视觉语言
- 形态：软圆点、短弧、星点、少量毛屑感小粒子。
- 色彩：结果猫咪主色 + 合成高光黄 `#FFD66B`；危险统一使用 `#F16F67`。
- 材质：扁平/轻柔发光，不做写实火花、重Bloom、复杂噪声Shader。
- 节奏：短促、快速收尾，不能长期遮挡棋盘。
- 原则：特效只消费 GameplayEvents，不修改核心玩法状态。

## 3. 单次合成 `CatMergeSucceeded`

### 触发
收到 `CatMergeSucceeded { position, resultLevel, ... }`。

### 表现
1. 结果点先出现约 70–100ms 的软圆高光扩张。
2. 同时喷出 6–10 个小型星点/毛屑粒子。
3. 结果猫咪可由 Client 表现层执行约 120–180ms 的 `0.88 -> 1.06 -> 1.0` 轻弹缩放。
4. 可选出现短暂 `+分数` 飘字，由 UI/VFX 协同，持续不超过约 450ms。

### 时长
总视觉寿命目标：约 300–500ms。

### 层级
- 高光/粒子位于猫咪上方。
- 不覆盖 HUD。
- 粒子最大扩散半径控制在结果猫直径约 0.6–0.9 倍以内。

### 叠加
允许多次合成同时存在；超过 3 个同屏合成时降低每次粒子数量，优先保持每个合成点有明确反馈。

## 4. 连续合成

连续合成不引入 Combo 数值，只增强表现节奏。

- 第二次及之后在短时间窗口内发生时，可略提高高光亮度或增加 1–2 个粒子。
- 不显示“x2/x3”倍率文案，避免误导为产品规则。
- 多级链式合成每一级都应有独立短反馈，不能用一个巨大爆炸跳过中间视觉。
- 同屏高频场景启用粒子总量上限，宁可减少数量，不遮挡猫咪。

## 5. 危险开始 `DangerStarted`

### 触发
Danger State 从 SAFE 进入 WARNING。

### 表现
- 危险线由低对比状态过渡到珊瑚红。
- 线条做缓慢呼吸：透明度/轻微粗细周期约 0.8–1.2s。
- 危险线附近可出现很轻的红色柔光，但不铺满屏幕。
- “危险”小布签可由 UI 显示；VFX 不重复创建第二套文字。

### 禁止
- 全屏红闪。
- 高频抖动。
- 强烈震屏。
- 会遮住猫咪接触点的大面积雾效。

## 6. 危险持续 `DangerProgress`

MVP 不要求显示精确倒计时数字。

可选视觉：
- 随 `elapsed / timeout` 轻微提升危险线呼吸强度。
- 最大强度仍不得压过猫咪轮廓。
- VFX 不自行判断 2 秒，只使用核心系统提供的进度。

## 7. 危险解除 `DangerCleared`

- 珊瑚红在约 150–250ms 内柔和退回 SAFE 低对比线。
- 可出现 3–5 个很轻的安全蓝绿小点向外消散，非必需。
- 不播放奖励式大特效，避免把“恢复安全”误解为得分事件。

## 8. Game Over `GameOver`

### 表现
- 棋盘整体在约 250–400ms 内轻微压暗/降低饱和度。
- Active Cat 保持可见，方便玩家理解结束现场。
- 默认不震屏；如后续体验测试需要，只允许一次非常轻微、短促的容器反馈，并重新经过 VFX Review。
- 结算页面具体进场不属于本任务。

## 9. 播放/打断规则
- Pause / 后台：所有时间型 VFX 同步暂停；恢复后从暂停点继续或按表现层安全规则结束，不能影响核心状态。
- Game Over：允许当前模拟步已经触发的合成短效收尾，但禁止 Game Over 后新产生“合成成功”表现。
- Restart：清理上一局所有残留粒子、Tween和警告光效。
- Scene销毁/切换：必须统一停止所有VFX句柄，不能留下跨局对象。

## 10. 性能预算（Local Web 首版）
- 单次合成粒子：默认 6–10，降级档 3–5。
- 同屏活跃轻粒子建议软上限：约 60；超过时优先减少新生成数量。
- 不要求后处理Bloom。
- 不引入第三方粒子/Shader框架。
- 优先使用 Cocos 原生 Sprite、Tween、简单 ParticleSystem2D 或等价低成本实现。
- 避免每粒子脚本级 Update；由引擎粒子/批量表现能力承担。

## 11. 资源需求
当前 v0.1 为规格，不声明正式资源已完成。

后续候选资源：
- 1 个软圆高光纹理。
- 2–3 个星点/毛屑小粒子纹理，可通过旋转/缩放复用。
- 危险线柔光可优先用简单半透明Sprite/材质参数实现。
- 不需要序列帧大图集作为首选方案。

## 12. Debug / QA
Local Web VFX Lab 或 Gameplay Debug 入口需支持：
- 手动触发每种合成等级效果。
- 连续触发 1/2/4/8 次合成压力场景。
- 切换 Danger Started / 50% / 95% / Cleared。
- 触发 Game Over。
- 显示当前活跃粒子数或等价统计。

QA 视觉证据：固定视口截图 + 合成/危险关键帧；需要验证节奏时录制短视频。

## 13. 用户审批后
批准本版本后，Client 可按本规格实现 GameplayVfxPresenter；正式视觉资源与实现仍需遵循 `project/ART_GUIDE.md` 和性能约束。
