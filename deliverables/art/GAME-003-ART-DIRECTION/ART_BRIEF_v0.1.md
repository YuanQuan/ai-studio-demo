# 美术制作简报 v0.1 — 猫咪合成小游戏

- 任务：`GAME-003-ART-DIRECTION`
- 状态：概念阶段；投入正式生产前必须获得用户批准
- 目标平台：Local Web、WeChat Mini Game、Douyin Mini Game
- 画面方向：竖屏 9:16

## 1. 视觉目标

制作一套原创、圆润、低细节、高轮廓可读性的猫咪合成视觉方向。任何视觉决定都必须优先支持“看清猫咪边界、看懂等级、看见危险线、理解合成”的玩法需求。

## 2. 风格要求

- 柔软圆润的贴纸绘本感。
- 温暖奶油色房间 / 软垫游戏盒氛围。
- 简洁深色描边，以平涂为主，只使用有限的柔和阴影。
- 不使用写实毛发、复杂表面纹理或明显向外延伸的长饰品。
- 角色可见轮廓应尽量接近运行时碰撞占地，避免视觉体积与物理体积明显不一致。

## 3. 角色概念要求

### 10 个等级
- L1–L10 每一级至少需要一个明确的内部特征或轮廓级区分点。
- L1–L3 由于会出现在 Current / Next 队列中，需要最强的小尺寸可读性。
- 高等级通过毛量、面部花纹、贴身小装饰和层次纹样逐步变得丰富。
- 不使用会制造虚假碰撞体积感的外置大装饰。

### 概念对照板目标
- 同时展示全部 10 个等级。
- 表达相对尺寸递进，但不把概念尺寸宣称为最终运行时像素尺寸。
- 包含等级标签和简短视觉主题标签。
- 概念对照板不是 Sprite Sheet（精灵表）。

## 4. 棋盘 / 场景概念要求

- 9:16 竖屏表现。
- 主玩法容器居中，并成为视觉主体。
- 背景细节使用低对比度，并尽量避开活跃物理判读区域。
- 危险线在棋盘上部清晰可见，但正常 `SAFE` 状态下不应制造过强紧张感。
- 顶部投放区域必须保持视觉干净，不能堆积装饰。

## 5. HUD 视觉方向要求

必须覆盖的语义元素：
- Current / 瞄准状态提示。
- Next 猫咪预告。
- 分数。
- 暂停 / 设置入口占位。
- 危险警告状态表现。

Art 只负责视觉表现。具体手势、交互点击区、位置、响应式布局和组件状态仍由 UI Agent 负责。

## 6. VFX 方向要求

- 合成：短促柔软的弹出感，以结果猫咪主色作为点缀，并搭配少量星点 / 毛屑粒子。
- 连锁合成：节奏逐步增强，但不能遮挡屏幕与邻近猫咪边界。
- 危险状态：危险线周边使用珊瑚红呼吸效果；不做全屏频闪。
- Game Over：使用柔和压暗 / 降饱和处理。

## 7. 生产与技术边界

v0.1 概念文件使用 SVG，便于本地查看和快速修改。它们不是最终运行时资产。

后续生产资产建议：
- 角色 Sprite：最终尺寸锁定后输出透明 PNG/WebP 或引擎 Atlas 可用格式。
- UI：仅在确有需要时制作九宫格切片；可复用的简单形状优先使用通用组件能力。
- Alpha 留白尽量紧凑，保证可见尺寸与物理尺寸关系容易理解。
- 最终导出密度和 Atlas 策略必须在生产前与 Client / Tech 确认。

## 8. 审批边界

在获得用户明确批准前，本包中的任何概念 Artifact 都不得被当作最终生产资产。批准后，Art 将把正式视觉基线更新到 `project/ART_GUIDE.md`，后续 UI / VFX 视觉工作必须遵循该基线。
