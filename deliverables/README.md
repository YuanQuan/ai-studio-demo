# Deliverables

Formal cross-agent outputs live under:

`deliverables/<role>/<TASK_ID>/...`

Roles:
- product
- art
- ui
- vfx
- tech_lead
- client
- server
- qa
- producer

Artifacts are versioned and never silently overwrite approved history. Only the concrete version explicitly approved by the user can unlock dependent downstream work.

Every Deliverable registers its files/asset paths and Task ID. Chat-only output is not a formal downstream input.
