# Cocos 运行时人工冒烟检查 v0.1

- Task：`GAME-010-COCOS-ENVIRONMENT-SETUP`
- Creator：`3.8.8`
- 当前实际工程：`ai-demo/`
- 场景：`assets/scenes/Gameplay.scene`
- 目的：补充自动构建无法替代的真实 GPU / 交互体验确认。

## 1. 启动

在 Cocos Creator 3.8.8 中打开当前 `ai-demo/` 工程，打开 `Gameplay.scene`，使用浏览器预览或 Web Desktop 构建预览。

通过条件：
- 页面正常进入 Gameplay，不停留在黑屏/报错页；
- 能看到奶油色背景、圆角棋盘、分数、下一只、暂停、危险线、投放提示；
- Console 没有阻塞运行的红色异常。

## 2. 投放

1. 在棋盘区域按住并左右拖动。
2. 确认顶部 Current 预览横向跟随。
3. 松手。

通过条件：
- 松手后生成一只真实物理猫；
- 猫受到重力下落并与底板/侧墙碰撞；
- 投放后短时间内不能立即重复释放；
- 满足约 0.25 秒 + 离开排除带后才能继续投放。

## 3. 合成 / 分数

连续投放相同等级猫，观察同级接触。

通过条件：
- 同级猫合成成高一级；
- 两个源猫不重复存在；
- 分数只在合成成功时增加；
- 合成点出现轻量放大/高光/加分反馈；
- 异级接触不合成。

## 4. 危险线

让堆叠接近顶部危险线。

通过条件：
- SAFE 时危险线低对比；
- 猫越线后进入 WARNING，危险提示出现；
- 猫全部回到线下后危险计时清零；
- 连续越线约 2 秒后进入 Game Over；
- Game Over 后不能继续投放或得分。

## 5. 暂停 / 重开

- 点击右上角暂停；确认物理与玩法计时停止。
- 恢复后继续运行，不应瞬间补算暂停期间的真实时间。
- Game Over 后点击结算遮罩文字区域重开。

通过条件：
- 重开后分数、危险状态、棋盘实体和 Current / Next 均恢复新局状态。

## 6. 当前视觉预期

本版本是**运行时集成原型**：角色和 UI 使用程序化 Graphics / Label 作为可运行占位实现，已经遵循批准的色彩、圆润轮廓与信息层级，但还不是最终生产美术资产。

因此本次重点审批：
- 玩法是否真的可运行；
- Physics / 输入 / HUD / VFX / Debug 是否已经正确接通；
- 基础布局和危险线是否具备正确语义。

最终角色 Sprite、精细 HUD 资产和正式 VFX 资源会在后续视觉生产/集成阶段继续替换和打磨。
